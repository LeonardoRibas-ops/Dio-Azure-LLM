# 🎡 LLM Game Wheel – Gire e Descubra sua IA!

Bem-vindo ao **LLM Game Wheel**, o projeto onde sorteamos IAs em vez de prêmios de bingo! 🧠✨

Este projeto foi criado como parte de um desafio de integração com **GitHub Copilot** e o **VS Code**, com foco em construir algo criativo, funcional e... divertido! 🤩

---

## 🧩 O que é isso?

Imagine uma roleta de jogo (tipo aquelas de TV) — mas ao invés de ganhar um carro, você ganha o nome de uma IA poderosa como:

- ChatGPT (OpenAI)
- Claude (Anthropic)
- Gemini (Google DeepMind)
- Mistral
- LLaMA (Meta)
- E mais...

## ⚙️ Como rodar localmente

### Clone o projeto:

```bash
git clone https://github.com/seu-usuario/llm-game-wheel.git
cd llm-game-wheel
```

### Inicie o backend:

```bash
cd backend
npm install
npm start
```

### Inicie o frontend:

```bash
cd frontend
npm install
npm run dev
```

Acesse em `http://localhost:5173` e divirta-se 🎉

---

## 🛠️ Configuração do Copilot

Na pasta `.vscode/settings.json` já deixamos tudo prontinho:

```json
{
  "github.copilot.enable": true,
  "editor.suggest.snippetsPreventQuickSuggestions": false
}
```
